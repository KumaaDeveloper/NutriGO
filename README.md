# NutriGO V1.0

NutriGO is a mobile application for ordering healthy food easily. This app helps users find healthy meals, place orders, save favorite foods, and manage their account balance in one platform.

## Features

* User registration using email and phone number with API integration
* Order healthy food directly from the application
* Add healthy food items to favorites
* View order history
* Top up account balance
* Change profile photo
* Supports profile image formats: JPG, PNG, and GIF

## Tech Stack

* Java
* Android Studio
* XML
* API Integration

## App Version

**NutriGO V1.0**

## Purpose

This application was created to make healthy food ordering easier and more convenient for users. NutriGO provides basic features that support a simple, fast, and user-friendly ordering experience.

## Supported Image Formats

The profile photo feature supports the following image formats:

* JPG
* PNG
* GIF

## Status

NutriGO V1.0 is the first version of the application and includes the main features for healthy food ordering.
